## 🔄 Optional: Enable Real LLMs

To use OpenAI instead of MockLLM:

```bash
# 1. Copy template
cp .env.example .env

# 2. Add your API key to .env
echo "OPENAI_API_KEY=sk-your-actual-key-here" >> .env
echo "OPENAI_MODEL=gpt-4o-mini" >> .env

# 3. Restart Jupyter
jupyter notebook
```

System automatically detects the API key and switches to OpenAI.
